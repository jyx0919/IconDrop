# IconDrop

[English](README.md) · [简体中文](README.zh-CN.md)

IconDrop 是一款用于批量修改 macOS 文件夹图标的菜单栏小工具。仓库里提供的是源码，目前没有可以直接下载打开的成品；照下面的步骤在自己的 Mac 上生成并运行即可。

## 功能

- 一张图片可应用到多个文件夹；若每个文件夹需要不同图片，可以建立多个任务。
- 左侧一次拖入一张图片文件；也可以复制图片文件或图片内容，点击「粘贴图片」或按 **⌘V**。
- 将图片主体统一放到透明的 512 × 512 画布上，可用「图案大小」滑块控制尺寸，并在应用前查看预览。
- 可选「移除背景」，使用 macOS Vision 识别主体。若识别失败，可关闭此选项或更换图片。
- 首次修改文件夹前备份其原有图标状态，以便之后恢复。

## 开始使用

需要一台运行 **macOS 14 或更新版本**的 Mac。目前没有安装包或预先编译好的版本，需要在自己的 Mac 上构建一次。**不需要安装 Git。**

1. 打开 Mac 上的**终端**。如果还没安装苹果的命令行开发工具，在终端输入 `xcode-select --install`，按提示完成安装。这套工具提供 Swift 编译器；即使通过 ZIP 下载源码，也需要安装。
2. 打开 [IconDrop 的 GitHub 页面](https://github.com/jyx0919/IconDrop)，点击 **Code → Download ZIP**，然后解压下载的文件。
3. 在终端输入 `cd`，按一次**空格**，把访达中解压出的 `IconDrop-main` 文件夹拖进终端，再按**回车**。这样终端就会进入项目文件夹。
4. 把下面两行命令复制到终端运行：

   ```sh
   bash scripts/build-app.sh
   open build/IconDrop.app
   ```

运行后，请到屏幕顶部的菜单栏寻找文件夹图标。IconDrop 不会弹出普通窗口，也不会出现在 Dock 中。如果没有看到图标，请看[这里的解决方法](#菜单栏里找不到-icondrop-图标)。以后再次使用时，在访达中双击 `build/IconDrop.app` 即可；只有更新或修改源码后才需要重新构建。

如果你习惯使用 Git，可以用 `git clone https://github.com/jyx0919/IconDrop.git` 和 `cd IconDrop` 代替第 2～3 步。构建脚本会生成 `build/IconDrop.app`、在本机签名，并自动尝试已安装的 macOS SDK。如果脚本提示找不到兼容的 SDK，请安装或更新苹果的命令行工具或 Xcode，再重新运行构建命令。开发者如需执行核心逻辑测试，可在兼容的 Xcode 工具链下运行 `swift test`。

## 使用方法

1. 点击 macOS 菜单栏中的 IconDrop 文件夹图标。工具不会显示 Dock 图标，也不会另开主窗口。
2. 左侧拖入**一张图片文件**，或复制图片文件/图片内容后点击「粘贴图片」、按 **⌘V**；右侧可拖入**一个或多个文件夹**。
3. 调整「图案大小」，按需开启「移除背景」，等待预览生成。
4. 点击「加入任务」。如果下一组文件夹需要另一张图片，重复第 2～4 步。如果所有文件夹都用同一张图片，把它们加入同一个任务即可。
5. 点击「应用全部」。面板会显示成功和失败数量，失败的文件夹会保留在任务列表中，方便重试。一个批次中，同一个文件夹不能重复加入。

点击面板外侧或再次点击菜单栏图标可收起面板；在面板右上角的「更多选项」中可退出 IconDrop。

### 恢复原来的图标

把要恢复的文件夹拖到**右侧**，点击「恢复所选原图标」。如果文件夹在 IconDrop 首次修改前有自定义图标，会恢复该图标；如果原来没有自定义图标，则恢复系统默认的文件夹图标。恢复需要原图标备份；若备份缺失或损坏，工具会报错，不会擅自覆盖图标。

备份保存在 `~/Library/Application Support/IconDrop/OriginalIcons`，成功恢复后会删除相应备份。底层库还提供 `restoreDefaultIcon(for:)`，可直接设回系统默认图标；当前菜单栏界面没有这项操作的独立按钮。

旧版生成的**自定义图标备份**可能不准确。遇到这类备份时，IconDrop 会跳过该文件夹并保留备份，不会覆盖当前图标；旧版备份无法自动修复。旧版生成的系统默认图标备份仍可正常恢复。

## 菜单栏里找不到 IconDrop 图标

菜单栏右侧空间不足时，macOS 可能隐藏新加入的图标，带摄像头缺口的 Mac 尤其容易遇到。此时 IconDrop 可能仍在运行。

1. 打开**系统设置 → 菜单栏 → 允许在菜单栏显示**，确认 **IconDrop** 的开关已打开。
2. 暂时关闭一两个不需要的菜单栏项目，腾出空间后 IconDrop 图标通常会出现。
3. 按住 **⌘**，把 IconDrop 图标拖到菜单栏更靠右的位置；若还有空间，再打开刚才关闭的项目。

苹果的[菜单栏使用说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp1446/26/mac/26)介绍了如何调整图标顺序。
